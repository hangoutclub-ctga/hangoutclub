# **App Name**: EscolaPlus

## Core Features:

- Profile Login: User authentication via pre-defined profiles with photo and 'nickname' selection, rather than email.
- Main Dashboard: Dashboard with quick actions for student management and financial overview.
- Student Registration: Form to register new student details (name, DOB, guardian, medical info, class, photo, address, phone). Conditional fields appear depending on student's age.
- Payment Status Input: Indication if book payment has been fully, partially, or not made, including an option for an input to note the value and date. (no database interaction)
- Student Roster: Displays a listing of registered students, categorized by course type (VIP, regular, scholarship, etc.). Includes student details like class, payment history, and grades. Filters, column visibility toggling, and printing options are available.
- Class Roster: Displays all registered classes with their responsible professor and course type, including a roster of linked students.
- Financial Overview: Displays income, expenses, and fixed costs, to show a summary for profit tracking. Users may add files like images/PDF receipts.

## Style Guidelines:

- Primary color: Dark blue (#30475E), echoing a sophisticated but trustworthy and calm tone.
- Background color: Light grey (#E8E6E7), complementing the dark blue, providing contrast for readability while evoking the look of textured white paper.
- Accent color: Dark red (#872B25) to highlight interactive elements.
- Body and headline font: 'PT Sans' (sans-serif), clean and readable, good for a data-rich, business-like display.
- Outline style icons in the accent color, to indicate actionable items.
- Use a grid-based layout to present information clearly and consistently. Cards for key data points with clear separation. Form elements should be aligned and easy to navigate.
- Use subtle animations to transition between pages/cards or on form input. Ensure that it doesn't distract from content.
